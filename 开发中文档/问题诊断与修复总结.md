# 前端功能异常问题诊断与修复总结

## 问题描述
1. **投票列表加载失败** — 加载投票列表返回 405/502
2. **抽奖效果无效** — 无法执行抽奖操作
3. **其他模块不可用** — 问卷、投票统计等相关模块无法正常工作

## 根本原因

### 原因 1：MySQL 认证失败导致后端启动失败（502 错误）
**症状**：
- 后端容器启动失败
- 错误日志：`Access denied for user 'root'@'172.18.0.4'`
- 前端所有请求返回 502 Bad Gateway

**根本原因**：
- Docker Compose 中 MySQL `root` 用户默认只允许本地连接（localhost）
- 后端容器内以不同 IP (172.18.0.x) 尝试连接时被拒绝

**修复方案**：
```yaml
# docker-compose.yml 中 mysql 服务添加：
environment:
  MYSQL_ROOT_PASSWORD: 123456
  MYSQL_ROOT_HOST: '%'    # 允许 root 从任何主机连接
```

### 原因 2：Vite 代理配置指向错误地址
**症状**：
- 错误：`connect ECONNREFUSED 10.135.2.131:8080`
- `host.docker.internal` 在你的网络中被解析为内部 IP，而非宿主机

**根本原因**：
- 初始配置使用 `target: 'http://host.docker.internal:8080'`
- 由于网络环境不同，解析结果不符预期

**修复方案**：
```javascript
// front-end/vite.config.ts
proxy: {
  '/api': {
    target: 'http://localhost:8080',  // 直接使用 localhost（容器已映射该端口）
    changeOrigin: true,
    ws: true
  }
}
```

### 原因 3：后端缺少 CORS 配置
**症状**：
- 浏览器预检 OPTIONS 请求被拒绝
- 跨域请求被浏览器拦截

**修复方案**：
新增 `CorsConfig.java`：
```java
@Configuration
public class CorsConfig {
    @Bean
    public CorsFilter corsFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowCredentials(true);
        config.addAllowedOriginPattern("*");
        config.addAllowedHeader("*");
        config.addAllowedMethod("*");
        config.addExposedHeader("Idempotency-Key");
        
        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", config);
        return new CorsFilter(source);
    }
}
```

### 原因 4：前端 HTTP 客户端缺少 baseURL 配置灵活性
**问题**：
- 在不同环境（dev、prod）下需要切换 baseURL，当前无法通过环境变量配置

**修复方案**：
```typescript
// front-end/src/lib/http.ts
private instance = axios.create({ 
  baseURL: (import.meta as any).env?.VITE_API_BASE ?? '' 
})
```
- 支持 `VITE_API_BASE` 环境变量覆盖
- 开发环境：使用 vite 代理（baseURL = ''）
- 生产环境：可设置 `VITE_API_BASE=https://api.example.com`
